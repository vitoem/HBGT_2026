# Herramientas Bioinformáticas para el Análisis de Genomas y Transcriptomas

## HBGT 2026

Bienvenido al sitio de materiales del curso.

Este espacio reúne el programa, materiales, ejercicios, datos y recursos utilizados durante el curso **Herramientas Bioinformáticas para el Análisis de Genomas y Transcriptomas**.

---

## 📚 Curso

El curso está orientado al aprendizaje práctico de herramientas y estrategias bioinformáticas para el análisis de datos genómicos y transcriptómicos.

Durante las sesiones trabajaremos con herramientas de línea de comandos, datos biológicos reales y recursos de cómputo para desarrollar flujos de análisis reproducibles.

---

## 🗓️ Programa

El curso está organizado en cuatro días de trabajo:

| Día | Tema |
|---|---|
| **Día 1** | Introducción y fundamentos |
| **Día 2** | Análisis de genomas |
| **Día 3** | Análisis de transcriptomas |
| **Día 4** | Integración y análisis de resultados |

> El contenido detallado de cada día estará disponible en las páginas correspondientes.
